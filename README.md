# Blog

A blog platform built with Django and Django REST Framework.
The backend exposes a REST API consumed by the frontend.

## Tech stack

- Python 3.12
- Django + Django REST Framework
- PostgreSQL
- Docker + Docker Compose
- uv 
- GitHub Actions
